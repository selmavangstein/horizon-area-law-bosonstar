# Original TDInf run scripts

These are the scripts that produced the paper's inspiral and full-signal posteriors.
They were run with the code in the parent directory (`main.py`, `analysis_utils.py`
and `debug_utils.py`), which has since been tidied without changing the sampling.
They are kept for provenance only; their paths refer to the machine they were run on.
Use `../run_tdinf.sh`, which uses identical settings with paths for this repository.

The raw samples they produced (thinned, in sampling coordinates) are in
`data/posteriors/raw/`.
